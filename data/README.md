# Synthetic diode observations

`synthetic_diode.csv` is **SYNTHETIC DATA**, generated by `examples/reproduce.py`, not measured device data or digitized manufacturer curves.

| Column | Unit | Meaning |
|---|---|---|
| `current_A` | A | Exactly controlled forward current; negligible current uncertainty is assumed |
| `voltage_V` | V | Compact-model voltage plus independent Gaussian noise |
| `sigma_voltage_V` | V | Known standard deviation, 0.0015 V for every observation |

Conditions: 300 K, 100 logarithmically spaced currents from 1 nA to 20 mA. Generator: NumPy `default_rng(2026)`. Truth: Is = 10⁻¹¹ A, ideality = 1.6, series resistance = 5 Ω. No filtering, baseline subtraction, outlier removal or other preprocessing is applied. The noisy observations are retained unchanged.

The companion metadata JSON records provenance and conditions. Original generated data are MIT licensed with this repository. No external raw dataset is redistributed. To reproduce:

```bash
python examples/reproduce.py --output outputs/reproduced
```

The generated CSV is written under `outputs/reproduced/data/`; the committed copy is the reference case. Do not apply this voltage-noise likelihood to a voltage-controlled experiment with noisy current without changing the statistical model.
